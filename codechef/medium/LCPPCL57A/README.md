## Problem

### Multiple Choice Question

What will be the output of this code,

```
#include <bits/stdc++.h>
using namespace std;

int main() {
  int n;
  cin >> n; 
  cout << "Your number is: " << n;  
}

```

if the input is

```
78.92

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-21T00:22:10.689Z  

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a;
    cin >> a;
    cout << "Your number is: " << a;
}
```
