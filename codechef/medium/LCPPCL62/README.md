## Problem

### Hello User

Listen

Complete the given program in IDE which should do the following:

- Declare a string variable x
- Accept a text user input - the name of the user - and store it in the variable x
- Print to the console "Hello" before the user defined name. Remember to add a space between "Hello" and x
### Sample 1:
Input
Output

```
Chef
```

```
Hello Chef
```

### Sample 2:
Input
Output

```
Chefina
```

```
Hello Chefina
```
