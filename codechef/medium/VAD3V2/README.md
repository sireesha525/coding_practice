## Problem

### Addition of Variables

Listen

Write a program which does the following

- Declare two integer variables a and b
- Assign the value 23 to a and 20 to b
- Output the sum of a and b to the console

To sum  **a**  and  **b**, you can print  **a + b**, like we did with numbers previously.

 **Expected output** 

```
43

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-13T05:22:29.975Z  

```c_cpp
#include <iostream>
using namespace std;

int main() {
    // Assign the value 23 to a
    int a=23;
    int b=20;
    cin>>a>>b;
    cout<<a+b;
}
```
