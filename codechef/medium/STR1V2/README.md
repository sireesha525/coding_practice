## Problem

### Creating a String

Listen

 **Strings**  are used for storing text.

A  **string**  variable contains a collection of characters surrounded by double quotes. Before declaring a variable as string the `string datatype` must be used.

For example:

```
string name = "Chef";

```

We print string like we print any other variable.

```
string name = "Chef";
cout << name;

```

### Task

Write a program which does the following

- Declare a string variable named fruit and assign the value "Apple" to it.
- Output the value stored in fruit to the console.
